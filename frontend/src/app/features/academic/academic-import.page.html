Revisa un lote antes de incorporarlo a tu organización. Se usan identidades existentes y autorizadas.

1. Prepara el archivo

El archivo CSV debe incluir studentId, programId, registrationCode y enrolledOn (AAAA-MM-DD). Utiliza los identificadores de estudiantes ya vinculados y programas activos de tu institución. Máximo 100 filas y 128 KiB.

El lote no crea cuentas estudiantiles ni concede autorizaciones. Los identificadores se pueden obtener desde la API de Estudiantes y Programas.
